# 7. 연말정산 정밀 계산 (결정세액·환급액)

## 배경

기존 연말정산 기능(직접 입력 / 내 거래 기반)은 **신용카드 등 소득공제액만** 산출했고, 실제로 얼마를 환급/추가납부하는지는 알 수 없었다. 사용자가 원한 것은 인적공제·4대보험·의료비/교육비/기부금/연금저축 세액공제까지 반영해 **결정세액과 환급/추가납부액**을 보는 것. 기존 카드 시뮬레이터는 그대로 두고(다른 탭에서 사용 중), **"연말정산 (정밀·결정세액)" 탭**을 새로 추가했다.

## 계산 흐름

```
1. 근로소득금액 = 총급여 − 근로소득공제(구간별 누진, 한도 2천만)
2. 과세표준    = 근로소득금액 − 종합소득공제
       종합소득공제 = 인적공제 + 연금보험료(국민연금) + 특별소득공제(건강·고용보험) + 신용카드 등
3. 산출세액    = 과세표준 × 기본세율(누진공제 방식, 2023~)
4. 결정세액    = 산출세액 − 세액공제 합계 (≥0)
       세액공제 = 근로소득 + 보험료 + 의료비 + 교육비 + 기부금 + 연금계좌
5. 정산        = 기납부세액 − 결정세액  (+환급 / −추가납부)
   지방소득세  = 결정세액 × 10% (별도 표시)
```

### 적용한 세법 상수 (TaxService 정적 메서드)

- **근로소득공제** `earnedIncomeDeduction`: 500만 70% → 1500만 40% → 4500만 15% → 1억 5% → 초과 2%, 한도 2천만
- **인적공제**: 기본 1인 150만 × (본인+부양가족), 경로우대 +100만/인, 장애인 +200만/인
- **기본세율** `progressiveTax`: 6%/15%/24%/35%/38%/40%/42%/45% 8구간 (누진공제액 차감)
- **근로소득세액공제** `earnedIncomeTaxCredit`: 산출 130만 이하 55%/초과 30%, 총급여별 한도(74만→66만→50만→20만)
- **보험료** 12%(100만 한도) · **의료비** (총급여 3% 초과분)×15% · **교육비** 15% · **기부금** 1천만 이하 15%/초과 30% · **연금계좌** 900만 한도, 총급여 5500만 이하 15%/초과 12%

> 신용카드 등 소득공제는 기존 `simulateYearEndSettlement`를 그대로 호출해 재사용한다(중복 로직 없음).

## 백엔드

- `dto/YearEndFullRequest` — 총급여, 카드 4종, 인적공제 인원(부양/경로/장애), 4대보험 3종, 세액공제 5종, 기납부세액
- `dto/YearEndFullResponse` — 단계별 금액 전부 + 결정세액 + 지방소득세 + 환급/추가납부(`refundOrPay`, +환급/−추가납부) + 가이드
- `TaxService.calculateYearEndFull(...)` + 정적 계산 헬퍼들(테스트 용이)
- `POST /api/tax/year-end/full`

## 프론트엔드

`Tax.tsx`에 탭 **"연말정산 (정밀·결정세액)"** 추가:
- 입력 폼: 급여·카드 / 인적공제 / 4대보험 / 세액공제 / 기납부 그룹으로 구획(`FieldGroup`)
- 결과 패널: ①근로소득금액 ②종합소득공제→과세표준 ③산출세액→세액공제→결정세액 단계별 표(`Row`, 공제는 초록 −표시), 마지막에 **환급(초록)/추가납부(빨강)** 강조 카드 + 가이드
- `types`에 `YearEndFullRequest`/`YearEndFullResponse`, `services.ts`에 `calculateYearEndFull()`

## 알려진 한계

- **간이 계산**: 자녀세액공제, 월세 세액공제, 표준세액공제(13만), 의료비 700만 한도/본인분 구분, 교육비 항목별 한도 등은 미반영. 가이드 메시지에 명시.
- 의료비 세액공제는 (의료비 − 총급여×3%)×15%로 단순화(본인·65세↑·장애인 무한도 가정).
- 지방소득세는 결정세액의 10%로 표시하되 환급/추가납부 정산은 **소득세 기준**으로 계산.
- 실제 신고는 국세청 홈택스/원천징수영수증 기준. 본 기능은 예상치 참고용.
