# Research Notes: Simplified Cashflow Ledger & Budget Dashboard

본 문서에서는 신규 가계부 단순화 및 현금흐름 대시보드 구축을 위한 기술적 연구 결과를 요약한다.

## 1. 카드 명세서 엑셀 파서 설계 (Excel Statement Parser Design)

### 결정사항
기존의 `HanaCardStatementParser` 구조를 본받아, `CardStatementParser` 인터페이스를 구현하는 `ShinhanCardStatementParser`와 `KBCardStatementParser`를 추가 구현한다.

### 핵심 파싱 알고리즘
- **헤더 키워드 매칭**: 각 카드사마다 출력 엑셀의 헤더 컬럼명(예: 거래일, 이용일, 승인일, 가맹점, 이용금액, 공급가액 등)이 다르므로, 대표 키워드 리스트를 정의하고 각 시트 행을 스캔하여 인덱스를 자동 매핑한다.
- **중복 거래 방지 (Natural Key)**: 중복 가계부 등록을 방지하기 위해 각 카드사별 고유 포맷(`CARD_COMPANY:DATE:MERCHANT:AMOUNT:INSTALLMENT`)으로 Natural Key(외부 참조 키)를 생성하여 DB 유니크 제약을 적용한다.

### 대안 비교
- **대안 A (국내 마이데이터 API 연동)**: 금융보안원 연동망 가입 및 개인 인증서 구현이 필수적이므로 로컬 독립 실행 웹앱에서는 기술적/법적 한계로 배제함.
- **대안 B (수동 매핑 범용 업로더)**: 유저가 컬럼을 직접 선택하게 하는 UI는 복잡도가 증가하므로, 주요 3대 카드사(하나, 신한, 국민)의 공식 엑셀 양식을 자동으로 탐지하는 파서를 우선 구현하는 것이 원칙에 부합함.

## 2. 가계부 및 예산 화면의 구조적 분리 (Ledger & Budget Architecture)

### 결정사항
기존 1100줄이 넘던 복잡한 `Budget.tsx` 컴포넌트를 기능별로 물리적 분리하여 가독성과 단순함을 개선한다.

- **`/ledger` (가계부 거래 관리)**: 거래 내역 조회, 필터링(자산별, 카드별, 기간별), 거래 내역 생성/수정/삭제 단일 모달 제공.
- **`/budget` (예산 설정)**: 카테고리별 예산 설정 및 간소화된 예산 대비 지출 현황 요약 제공.
- **`/api/transactions` API 최적화**: 자산 이동(이체) 및 수입/지출 처리 시 비즈니스 규칙 검증 보강.

## 3. 현금흐름 및 예산 대비 지출 대시보드 시각화 (Dashboard Visualization)

### 결정사항
- 사용자의 현금흐름을 한눈에 볼 수 있도록 대시보드 상단에 소득(Inflow), 지출(Outflow), 자산이동(Transfer), 투자/보험 비중을 노출한다.
- Recharts를 사용하여 신용카드 vs 체크카드 vs 현금 사용률 비중을 시각화한다.
- 예산이 설정된 카테고리의 경우 실제 지출이 예산의 80%를 넘을 시 노란색 경고, 100%를 초과할 시 빨간색 경고를 노출하는 진척도 게이지(Progress Bar)를 구현한다.
